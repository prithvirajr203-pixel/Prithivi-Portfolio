## Getting Started

Clone the repository:

```bash
git clone https://github.com/prithvirajr203-pixel/Prithivi-Portfolio.git
cd Prithivi-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
